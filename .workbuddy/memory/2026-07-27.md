## 颜色通路修复 + 几何多样性引导（红色笔记本成功）

用户验证笔记本"惨不忍睹"（只看到平板/底座，全 box 无颜色）。根因是颜色通路三处断点：
1. DSL API `box({material})` 只有 'metal'|'plastic'|'glass' 枚举，无 color 参数 → LLM 无法表达"红色"；
2. placement 把 IR `material.color` 丢进 `metadata.color`（渲染器不读 metadata）；
3. 渲染器优先级 materialPreset > node.material，preset 存在时颜色被吞。

修复 4 文件：
- `generated-geometry-dsl-builders.ts`：9 个几何构造函数加 `color?/roughness?/metalness?`（hex 字符串），新增 `hexToVec3`，`makePartBuilder` 把颜色接进 IR SerializableMaterial；
- `generated-geometry-placement.ts`：新增 `vec3ToHex`，color 从 metadata 改写到 `node.material.properties.color`；有 tint 时查 `DEFAULT_MATERIALS` 合并 preset 基础值（metal+红=红金属）。`DEFAULT_MATERIALS`/`MaterialPreset` 从 `@pascal-app/core/schema` 桶文件引（避开深层子路径坑）；
- `generated-mesh/renderer.tsx`：材质优先级反转 node.material 优先于 materialPreset；
- `generator-dsl-llm-loop.ts`：prompt 加颜色文档 + 规则9（颜色表达）+ 规则10（几何多样性），prompt 版本 1.0.0→1.1.0。

**注意**：MaterialSchema.properties.color 是 hex 字符串，IR SerializableMaterial.color 是 Vec3——两层之间要 vec3ToHex 转换。'plastic' 不在 MaterialPreset 枚举里，不能 fold 进 material.preset，只能查 DEFAULT_MATERIALS 合并基础值。

验证：用户第二次跑"红色笔记本"全绿——红色外壳/底座、黑色键帽区分、屏幕竖起。
