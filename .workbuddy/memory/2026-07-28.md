## unreachable node warning 修复

- **问题**：每次启动 ~100 条 `[Scene] Removing unreachable node` 警告（generated-assembly/mesh 节点）
- **根因**：`use-scene.ts` 的 `setScene` 加载时做可达性清理，但 `prepareSceneGraphForSave` 保存时只过滤 isTransient 节点，不做可达性清理。孤儿节点被持久化 → 启动清理 → 再保存 → 循环
- **修复**：在 `packages/editor/src/lib/scene-save.ts` 的 `prepareSceneGraphForSave` 添加二阶段清理：
  1. 第一阶段：剥 transient 节点 + 修复引用（原有逻辑）
  2. 第二阶段：`collectReachableNodeIds` → 删除不可达节点
- **新增测试**：`scene.test.ts` 加 `drops unreachable nodes before save` 用例
- 变更文件：
  - `packages/editor/src/lib/scene-save.ts` — +40 行（`getNodeChildIds`、`collectReachableNodeIds`、二阶段清理）
  - `packages/editor/src/lib/scene.test.ts` — +25 行（新测试用例）
